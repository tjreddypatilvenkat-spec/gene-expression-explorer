# 🧬 Gene Expression Data Explorer

An interactive Python-based Computational Biology web application
for exploring, visualizing and analyzing gene expression datasets.

## Included Features

- CSV dataset upload and processing
- Interactive gene expression visualization
- Dataset overview and preview
- Statistical analysis and descriptive summaries
- Expression distribution histograms
- Gene expression correlation matrix
- Data export and CSV downloads
- Interactive web-based interface

## Technologies Used

- Python
- Streamlit
- Pandas
- Matplotlib

## Analysis Workflow

1. Upload a gene expression dataset.
2. Explore the dataset structure.
3. Select a numerical gene variable.
4. Generate expression visualizations.
5. Examine statistical summaries.
6. Analyze correlations.
7. Download the results.

## Application

Live Website:https://gene-expression-explorer-elyroyxdohsvuokyuve2se.streamlit.app/

## Important Note

The sample dataset is illustrative and is intended
for testing the application's visualization features.
It does not represent experimental biological findings.
